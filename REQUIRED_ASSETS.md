## 🎨 IMAGE SPECIFICATIONS

### General Guidelines:
- **Format:** JPG or PNG (PNG for images with transparency)
- **Optimization:** Compress images for web (use tools like TinyPNG, ImageOptim)
- **Quality:** High resolution but optimized file size
- **Aspect Ratio:** Maintain consistent aspect ratios within each section
- **Color Profile:** sRGB color space

### Recommended Tools for Optimization:
- Image compression: TinyPNG, Squoosh, ImageOptim
- Video compression: HandBrake, FFmpeg
